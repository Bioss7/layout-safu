# Международное сотрудничество

Самостоятельная страница `/international/`. Источник: Figma International,
файл `oozCCezWvGMRB5pAdXVMtT`, страница `1:6`; кадры `102:1857` (1920)
и `102:2684` (390). Редакторский `template-international` не заменяется.

## Устройство и адаптация

HTML, SCSS с БЭМ, Vanilla JavaScript; локальная библиотека Swiper используется
для четырёх слайдов первого экрана. Общая оболочка подключена штатными маркерами.
Брейкпоинты: 1400, 1200, 992, 768, 576 px; ниже 390 блоки продолжают расширяться
по содержимому. На 320 длинные слова могут переноситься внутри слова.

| Компоненты                          | Источник адаптации                                                            |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| hero, слайдер                       | main: разметка, hero.scss, hero.js; оставлен один слайдер без вкладок главной |
| marquee, section-header, link-arrow | main: соответствующие блоки и common.scss                                     |
| life-tabs, life-panel, life-card    | main: life.scss и life-tabs.js                                                |
| partner-network, partner-logos      | partners: partner-network.scss, tabs.js, logos.js                             |
| breadcrumbs, pagination             | events: соответствующие SCSS и разметка                                       |
| button                              | abiturient: button.scss и разметка                                            |

Копии адаптированы локально; исходные страницы не изменены. Общие шапка, подвал,
поиск и меню используют существующие исходники без переопределения их оформления.

Новые stat-card/statistics, info-card, contact-card, person-card/people нужны
для композиций данного макета: существующие карты контактов, карточки отзывов
и формы не воспроизводят их структуру. Контейнеры и обёртки секций отдельно
новыми компонентами не учитываются.

В мобильном кадре меняются порядок карточек статистики, заголовок первой
информационной карточки, тексты новостей и часть адресов. Эти варианты сохранены
буквально; это не исправление редакторского содержания. Неизвестные адреса
остаются ссылками `#`, телефоны и почта используют `tel:` и `mailto:`.

## Демонстрационные состояния

Начальное состояние каждой секции соответствует Figma. По согласованию
с пользователем остальные три слайда hero, объявления, три дополнительные
вкладки стран и дополнительные карточки сотрудников заполнены демонстрационно.
В этих состояниях есть явная подпись «Демонстрация»; вымышленные реальные
телефоны и адреса не добавлялись. У каждой из пяти вкладок сотрудников четыре
страницы по две карточки, при смене подразделения выбрана первая страница.

Пагинация конечная; стрелки недоступны на соответствующей границе. Работают
клавиатура, касания и свайп hero. Ленты партнёров останавливаются при наведении
и фокусе; при reduced motion анимация отключена и доступна нативная прокрутка.

Hero синхронно переключает заголовок, описание, подпись, номер и фотографию.
Пути изображения и его мобильного варианта, а также alt задаются в data-атрибутах
соответствующего слайда. Первый слайд использует точные экспорты Figma;
три демонстрационных — локальные фотографии из блока новостей.

## Геометрия и ресурсы

Локальный, игнорируемый Git кэш — `figma/`: index.json, context-_.txt,
properties-_.json, mobile-tabs.json, fills.json, assets.json и эталоны кадров.
Индексы указывают node ID и назначение; исходные координаты Figma сохранены
без округления в абсолютной системе холста. Начала кадров: (668, 3047)
и (2630, 3047); координаты браузера отсчитываются от страницы.

Фотографии hero экспортированы целыми группами `102:1896` и `102:2726`,
портрет — из компонентов `116:7127` и `117:8433`. Учтены реальные
мобильные overrides логотипов: `117:7999` использует «Севералмаз»,
хотя сгенерированный код MCP ошибочно повторяет изображение соседнего экземпляра.
Подтверждение — mobile-partner-fills.json и визуальное сравнение с эталоном.
Все используемые изображения и SVG локальные; временных URL в коде нет.
Неиспользованные выгрузки лежат только в игнорируемом кэше.

Семь изображений новостей экспортированы непосредственно из видимых слоёв
`I113:6563…6566;2021:1797` и `I117:7919…7921;2046:8061`.
Это сохраняет точное кадрирование, которое теряется при подстановке исходных
фотографий через обычный object-fit. Экспорт выполнен read-only Plugin API
`exportAsync({format: "PNG"})`; свойства исходных заливок — news-crops.json.

Коррекция видимой базовой линии HS_LunaObscura — `top: 0.15em` на текстовых
обёртках. На снимках исходный WOFF2 рисовал глифы приблизительно на 4 px выше
Figma при 24 px и на 8 px при 56 px. Коррекция не меняет padding и line-box.
Для мобильных вкладок people исходный line-height равен 151.99639797210693%,
но фактическая высота текста в Figma — 63/42 px для трёх/двух строк.
CSS использует вычисленные 21 px (63 / 3 = 42 / 2), сохраняя padding 14×12,
высоты кнопок 91/70 и gap 12. Исходное процентное значение сохранено в кэше.

## Проверка

`pnpm build`, `pnpm project:data:check`, `pnpm check:project-data`,
`pnpm check:assets`, `pnpm check:international`; форматирование проверяется
для новых HTML/SCSS/JS и затронутых инструментов.

Браузерная проверка: 320, 390, 480, 575, 576, 577, 672, 767, 768, 769,
880, 991, 992, 993, 1100, 1199, 1200, 1201, 1300, 1399, 1400, 1401,
1600, 1920, 2560 px. Проверяются overflow, изображения, шрифты, дубли ID,
положения секций на эталонных ширинах, все вкладки и пагинация,
свайп, touch, клавиатура, Escape меню и раскрытие подвала.

Снимки и результаты — `screenshots/international/` (локально, вне Git).
На comparison-1920.png и comparison-390.png слева Figma, справа браузер.
Положения и высоты секций содержимого на 1920 и 390 совпадают с исходными
кадрами; допуск проверки координат 2 px. Нормальное и reduced motion
поведение проверены отдельно. Автовысота hero пересчитывается после загрузки
шрифтов, чтобы первый мобильный кадр не зависел от скорости загрузки WOFF2.

Открытые отличия общей оболочки отражены в реестре замечаний. PHP, импорт,
деплой, git add/commit/push не выполнялись.
