# Источники шрифтов

- Cakra Normal — локальный идентичный файл из `template-international/assets/fonts/`; лицензия рядом в `Cakra-OFL.txt`.
- Tilda Sans VF — официальный комплект https://static.tildacdn.net/downloads/TildaSans/TildaSans-VF_TTF_Web.zip, получен 2026-11-06. Официальное описание и условия бесплатного использования: https://tilda.cc/lp/tildasans/.
- Montserrat для пагинации — существующее общее подключение из `assets/scss/_fonts.scss`.
