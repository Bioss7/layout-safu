# Фоны страницы партнёров

В секциях development и CTA используются цельные lossless WebP, включающие карту,
синюю заливку и свечения. Текст, кнопки и иконки остаются в HTML. Фоны подключаются
через `cover` с центрированием, мобильные варианты — до 576px включительно.

| Секция | Узел desktop | Узел mobile | Размеры WebP desktop / mobile |
| --- | --- | --- | --- |
| Development | `1:966` | `9:967` | 3840×736 / 716×736 |
| CTA | `1:1046` | `9:1038` | 3840×1080 / 780×1612 |

Источник: [макет партнёрам](https://www.figma.com/design/CGbmxuN7RRy1plfxfak9U1/),
параметры получены 29.10.2026. Плотность — 2×. Обрезка совпадает с границами секций;
зеркальное отражение CTA уже включено в изображение.

Повторная сборка из `layout-safu/`:

```sh
node tools/render-partners-backgrounds.mjs
```

Скрипт использует Chrome, Playwright, Sharp и исходные PNG/SVG из
`partners/assets/img/`. Параметры слоёв и SHA-256 исходной карты сохранены в
`tools/partners-backgrounds.json`. Исходные ресурсы нужны для повторной сборки,
даже если больше не подключаются напрямую в CSS. Документ Figma скрипт не меняет.

Фоны собраны локально по согласованному запросу пользователя. При изменении
макета сначала обновить параметры из соответствующих desktop и mobile узлов,
затем пересобрать изображения и визуально сверить обе версии.
