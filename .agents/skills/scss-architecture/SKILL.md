# SCSS компонентов

Зона верстальщика — SCSS назначенной страницы. Блоки подключать через @use
в <page>.scss; в блоках использовать @use "../_mixins" as * и @use "../_vars" as *.
Токены — своей страницы; common.scss — общие элементы, typography.scss — типографика.

## Селекторы и раскладка

- Плоские .block__element; вложенность — для модификаторов и псевдоклассов/псевдоэлементов. Один компонент со всеми вариантами, состояниями и адаптивами — в одном файле; не переносить переопределения к соседним блокам.
- Вариант элемента оформлять одним классом .tabs__tab--faq, без .faq .tabs__tab или .tabs.tabs--line. Не наращивать специфичность, не использовать межфайловый @extend для обхода структуры.
- Основная раскладка — Flexbox: flex-wrap, flex-basis, min-width: 0, gap. Grid допустим для простых компонентов или при явной необходимости двумерной сетки; нетривиальный выбор кратко пояснять в комментарии или документации. Имена классов сохраняют БЭМ и назначение компонента; суффикс *-grid сам по себе не запрещён.
- До 1920px — резиновая раскладка, выше — центрирование. Для геометрии — размеры в px, проценты, простые calc(), min() и max(). CSS clamp() запрещён. Высоту текстовых блоков не фиксировать.
- Секции — явные padding-top/padding-bottom, без внешнего margin и скрытого деления общего --section-gap. Внутренние ряды — gap. Не удваивать расстояния соседей и не подменять подтверждённую заливку просвечивающим фоном страницы.

## Адаптивы

- Основные точки: 390, 576, 768, 992, 1150, 1200, 1440px. Сохранять другие существующие точки страниц, включая 460px; точка 900px исключена.
- Только @include breakpoint($bp-992) с одной переменной $bp-* из _vars.scss; имя соответствует пиксельному значению. Миксин задаёт max-width.
- Для каждой точки один блок внизу файла компонента, от большего к меньшему. Повторы объединять; лишние и унаследованные декларации удалять. Стили выше наибольшей точки — базовые.
- Запрещены второй аргумент, null, числовые media-границы, screen-*, диапазоны и арифметика границ в компонентах. При переносе правил проверять каскад и сбрасывать свойства, которые не должны переходить на меньшую ширину.
- Новая точка — только с явного согласия пользователя с указанием ширины, блока и причины. Существенное перестроение на существующей точке также пояснять.
- font-size, line-height, letter-spacing задавать явно на точках, без интерполяции через calc(), vw и цепочки переменных.

## Оформление

- Оформление и переносы брать из макета, требований или подтверждённого компонента. При нехватке данных сохранить подтверждённое оформление/наследование и сообщить недостающий параметр; запасной вариант применять только при явном согласовании. Доступный фокус сохранять.
- Подтверждённые переносы оформлять классами br, br-390, br-1440, br-above-1440, br-hide-390 по аналогии с главной. На промежуточных ширинах предпочитать естественный перенос.
- Цвета — из токенов. Непрозрачные цвета и остановки градиентов — HEX; rgb()/rgba() — только для прозрачности. currentColor, transparent и наследование сохранять по назначению.
- Дробные размеры, координаты, рамки и тени сохранять, если они влияют на совпадение с макетом. Округлять допустимо после проверки геометрии, переносов и накопленного сдвига; исходные значения хранить в кэше. Предпочитать простую раскладку без компенсационных формул. Осмысленные em для letter-spacing и безразмерный line-height не округлять до целого.
- font, background, mask и -webkit-mask раскрывать на отдельные свойства, включая font: inherit. Другие сокращения допустимы при намеренно заданных значениях без нежелательных сбросов; нетривиальное исключение пояснять в документации.
- Одноцветные иконки — маска с background-color: currentColor. Тень прямоугольника — box-shadow, прозрачного контура — filter: drop-shadow. Не запекать тени в изображения; у готового ресурса проверить чистый экспорт или корректное отделение внешней тени.

## Состояния и прокрутка

- Оформлять применимые hover, active, focus-visible, disabled, readonly, filled/placeholder-shown, invalid, autofill, checked, selected, expanded. Неприменимые состояния не добавлять.
- Не придумывать поворот, масштабирование и прозрачность. Transition — в базовом селекторе для реально меняющихся свойств, без all; учитывать prefers-reduced-motion.
- Вкладки: overflow-x: auto и скрытая полоса; grab/grabbing для drag-scroll. Поведение — зона специалиста JavaScript.
- Textarea и длинные списки: ограниченная высота, overflow-y: auto, тонкая полоса, ползунок var(---Accent-Accent-100, #00AEEF), scrollbar-color/width и ::-webkit-scrollbar-thumb. Общие правила скроллбара — в миксине.
- Input сохраняет нативное перемещение длинного значения без фиктивного вертикального скроллбара. Активный пункт/вкладка прокручивается внутри контейнера без ненужного перемещения страницы; фокус остаётся видимым.

## Читаемость и замечания

Не сжимать авторские стили. Краткие SCSS-комментарии допустимы для неочевидных
причин и ограничений; не пересказывать очевидный код и не добавлять комментарии-маркеры.
Развёрнутые пояснения хранить в документации, открытые расхождения — в реестре по
[правилам проекта](../../project.md#реестры). Согласованный запасной цвет
сохранять обычным правилом; решённое замечание удалять.
Форматирование и команды — в [project.md](../../project.md#команды),
проверка — в [interface-review](../interface-review/SKILL.md).
