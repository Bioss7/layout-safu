# JavaScript компонентов

- Один файл — компонент или конкретная обязанность; HTML подключает каждый файл отдельным обычным <script defer>. Компонент самостоятельно инициализируется после готовности DOM, без глобальных авторских переменных и повторных обработчиков. Production-файлы самодостаточны, без import/export. Vendor подключается отдельным локальным файлом перед зависимым компонентом, лицензия сохранена.
- Явные небольшие функции и понятные имена. Авторский код не сжимать. Нетривиальную логику объяснять русскими комментариями: причина, ограничение, обработка края. Лицензии vendor не переводить.
- Обработчики на js-*, поиск внутри компонента. Data-* — ключи/настройки. Состояние через БЭМ, hidden, aria-*. Геометрия — CSS. JS допустим для scrollLeft/scrollTop и определения доступного места выпадающего списка с русским пояснением.
- Отсутствующий компонент не вызывает ошибку. Клавиатура, фокус, Escape и aria-состояния работают согласованно.
- Drag-scroll: Pointer Events и scrollLeft; touch нативный; grabbing при drag, случайный click подавляется. Обычный click/клавиатура сохраняются.
- Существенное неоднозначное поведение уточнять после проверки требований/макета/кода. Демонстрацию не выдавать за реальную отправку.
- Поля проверяют нужные ограничения, ошибки связаны aria-describedby. Без обработчика данные не отправлять и не сохранять.
- Проверять переполнение, длинные значения, pointercancel, клавиатуру и смену ширины. Авторские комментарии в тестах тоже русские.
