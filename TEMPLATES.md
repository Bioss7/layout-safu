# Контентные шаблоны для редактора Bitrix

Три самостоятельные страницы показывают наполнение обычными HTML-тегами.
Оформление применяется через родительский класс; текущие страницы сайта не заменяются.

| Адрес | Название в /ui/ | Состояние |
| --- | --- | --- |
| /template-main/ | Шаблон — Главная | Реализована |
| /template-abiturient/ | Шаблон — Абитуриент | Реализована |
| /template-international/ | Шаблон — Иностранный абитуриент | Реализована; подключён Cakra |

## Контракт редакторского контента

Родитель .template-content находится снаружи содержимого редактора. Классы на
отдельных тегах не нужны. Поддерживаются h1–h6, p, a, ul/ol/li, strong/b, em/i,
sup/sub, hr, img, picture, figure/figcaption и семантические таблицы. Один h1 на страницу.

    <article class="template-content template-content--international" aria-labelledby="page-title">
      <h1 id="page-title">Название страницы</h1>
      <p>Абзац со <strong>значимым текстом</strong> и <a href="#">ссылкой</a>.</p>
      <h2>Раздел</h2>
      <ul><li>Пункт списка<ul><li>Вложенный пункт</li></ul></li></ul>
      <img src="image.png" alt="Описание" width="1184" height="636">
      <table>
        <caption>Название таблицы</caption>
        <thead><tr><th scope="col">Колонка</th></tr></thead>
        <tbody><tr><td>Значение</td></tr></tbody>
      </table>
    </article>

Маркеры ul создаются абсолютным li::before; текст получает padding-left: 14px.
Вложенные списки поддерживаются. Обычный img работает непосредственно в родителе
и внутри абзаца; picture и figure не обязательны. figure с figcaption доступен для подписи.
Демонстрационная фотография — готовое кадрирование узла 112:3628, а не квадратная
исходная заливка. Поэтому обычный img сохраняет композицию без специальных классов.
Сохранён небольшой интервал под изображением по геометрии кадров.

Таблицы и все вложенные теги остаются без классов. JavaScript автоматически
находит .template-content table: редактор вставляет только обычную таблицу.
Скрипт создаёт обёртку, область прокрутки, копию подписи и верхний индикатор
со служебными data-table-* атрибутами, без классов. Исходный caption сохраняется
для доступного имени таблицы. Повторная инициализация не создаёт дубликаты.
Область прокручивается мышью, касанием и с клавиатуры. При отключённом JavaScript
работает нативная полоса снизу через SCSS, caption прокручивается вместе с таблицей.
Видимость нативной полосы зависит от настроек ОС и браузера.

## Состояния ссылок

Все ссылки внутри .template-content оформляются по тегу a, без классов.
Источник — Figma 0g0if0G5GAMLjX6ZQU5GhP, секция 76:3779:
обычное состояние #007AFF, hover #00AEEF, visited #5856D6.
Начертание Montserrat Medium 500, подчёркивание во всех состояниях;
размер и line-height наследуются от окружающего текста (18/26, 16/24, 14/20).
Наведение на посещённую ссылку имеет приоритет и также даёт #00AEEF.
Видимый фокус с клавиатуры сохранён; шапка, подвал и хлебные крошки не изменены.
Остальные начертания и расширенная типографика отложены по просьбе пользователя.

Проверка: node tools/check-content-links.mjs. Для visited используется отдельный
пустой профиль Chrome, реальный локальный переход и возврат. Цвет подтверждается
пикселями снимка, поскольку getComputedStyle скрывает посещённое состояние.
Результаты и снимки — screenshots/content-links/; свойства Figma —
template-main/figma/link-states-properties.json.

## Проверка

Выполнены pnpm build, check:assets (3 теста), check:project-data (5 тестов),
check:templates и отдельная проверка форматирования новых HTML/SCSS/JS.
Браузерная проверка охватывает каждую страницу на 20 ширинах: 1920, 1441, 1440, 1439,
1201, 1200, 1199, 993, 992, 991, 769, 768, 767, 577, 576, 575, 480, 391, 390, 389 px.

Проверены шрифты и начертания, загрузка изображения, цвет хлебных крошек, маркеры,
отсутствие горизонтального переполнения, вложенный список, длинное слово, img
в абзаце, подпись figure, нативная прокрутка таблицы мышью, касанием и с клавиатуры,
таблицы с 2/3/6 колонками и объединёнными ячейками,
открытие меню/Escape и раскрытие подвала. Ошибок JS и загрузки ресурсов нет.

Визуальная сверка выполнена на 1920 и 576 px. Снимки семи основных ширин, metrics.json
и comparison-1920.png / comparison-576.png — в screenshots/<имя-шаблона>/.
На сравнениях слева Figma, справа браузер. При включённом JavaScript верхний индикатор сохранён как в макете;
без JavaScript работает нативная полоса снизу и высота таблицы может отличаться. Для положения статьи,
её ширины и блоков выше таблицы сохраняется допуск 2 px.
У Абитуриента изображение 126:6923 выше собственного figure на 3.016 px; обычный
img сохраняет пропорции, допуск его высоты на 1920 — 4 px. Сглаживание глифов
между Figma и Chrome может различаться.

Существующий мобильный подвал имеет высоту 952.53 px вместо 944.63 px в Figma;
сохранён по требованию пользователя. Общая format:styles:check отмечает прежнее
форматирование ui/ui.css; этот файл не изменялся. Сборка сообщает предупреждения
о старых CSS-хаках reset существующих страниц.

Этап ограничен статической вёрсткой. PHP, подключение стилей к самому редактору
Bitrix, импорт и деплой не выполнялись. Коммиты не создавались.
