# Абитуриент

Самостоятельная статическая страница `/abiturient/`. Исходники и ресурсы других страниц не изменяются.

- Разметка: `index.html`.
- Стили: `src/scss/abiturient/`, отдельный файл для каждого БЭМ-компонента.
- JavaScript: каждый компонент из `src/js/abiturient/` подключается отдельным обычным `<script defer>` и самостоятельно инициализируется после готовности DOM. Сборка создаёт `assets/js/abiturient-<component>.js`. Локальный `abiturient/assets/vendor/swiper-bundle.min.js` подключён перед отзывами; объединяющей точки входа нет.
- Ресурсы: `public/abiturient/assets/`, изображения распределены по блокам. Unbounded — локальные variable WOFF2 200–900, Montserrat — локальные variable WOFF2. Лицензии находятся рядом со шрифтами.
- Header, footer, marquee и отзывы перенесены из готовой главной страницы в собственные файлы. Изменения их оформления действуют только здесь.

## Макеты

[1920](https://www.figma.com/design/aVwbPxZ5FUxYkvTcvME566/?node-id=4147-5075), [390](https://www.figma.com/design/aVwbPxZ5FUxYkvTcvME566/?node-id=4147-4874), [UI-kit](https://www.figma.com/design/aVwbPxZ5FUxYkvTcvME566/?node-id=4168-6354).

Промежуточные состояния: 1440, 1200, 1150, 992, 900, 768 и 390px. Страница центрируется на экранах шире 1920px. Сетки построены на Flexbox, отступы секций — padding. Вкладки прокручиваются мышью, касанием и клавиатурой; карта целиком заменяется вместе с городом. FAQ сохраняет раскрытые вопросы при переключении категорий.

Локальные эталоны и состояния: `figma/desktop-1920.png`, `mobile-390.png`, `ui-kit.png`.
Индекс узлов/экспортов — `figma/index.json`, контекст — `figma/context.json`. Кэш не входит в production.
Экспорт MCP группы людей имел белый фон. Прозрачные PNG собраны из оригинальных заливок
по точной геометрии/crop-transform группы скриптом `tools/export-applicant-people.mjs`.
На странице это одна картинка с адаптивным source; исходные фотографии хранятся только в кэше.

Единый источник замечаний — `ui/data/remarks.json`. [STYLE-REMARKS.md](STYLE-REMARKS.md) генерируется командой `pnpm remarks:md`, вручную его не редактировать.
Актуальный перечень также выводится в `/ui/`. Для неизвестного hover используется var(---Accent-Accent-100, #00AEEF) по согласованному правилу проекта. После исправления удалить запись JSON и ссылку по ID в коде, затем обновить Markdown; в перечне и UI остаются только открытые.

## Данные и действия

Контакты Архангельска и начальная категория FAQ взяты из макета. Содержимое остальных вкладок демонстрационное, панели помечены `data-demo="true"`; вымышленные действующие контакты не используются. Числа и тексты макета не являются подтверждёнными актуальными данными приёмной кампании.

Форма проверяет тему, имя, email и вопрос. Отправка, сохранение персональных данных и серверный обработчик отсутствуют; после проверки показывается сообщение, что вопрос не отправлен. Четыре карточки «Больше возможностей» оформлены ссылками с согласованными временными `href="#"`; при интеграции заменить адресами разделов. Остальные внешние переходы без предоставленного адреса и видео открывают поясняющее окно. Каталог ведёт на существующий `/programs/`.

## Проверка

`pnpm build`, затем `pnpm preview --host 127.0.0.1 --port 4173` и в другом терминале `node tools/check-abiturient.mjs`.

Проверка охватывает адаптивы, загрузку изображений/шрифтов, единственный JS-бандл, вкладки и карту, FAQ, слайдер, клавиатуру, форму, меню, подвал, диалог и уменьшенную анимацию. Скриншоты сохраняются в игнорируемую папку `screenshots/abiturient/`.

PHP-интеграция и деплой не выполняются. Commit и push пользователь делает самостоятельно.

## Форматирование стилей

`pnpm format:styles` — форматирование SCSS страницы и служебного CSS;
`pnpm format:styles:check` — проверка. Prettier: 2 пробела, LF, 100 символов.
`pnpm build` автоматически форматирует итоговый CSS «Абитуриента» и UI,
сохраняя минификацию CSS остальных страниц и JavaScript.

Основные брейкпоинты: 390, 768, 900, 992, 1150, 1200 и 1440px.
На 900px hero переходит в одну колонку: текст и группа людей уже не помещаются рядом.
О новой точке вне списка нужно сообщать до изменения, указав блок и причину.

Бейдж «Твой старт» остаётся SVG: тень — векторная копия исходных контуров
со смещением 3px вправо и вниз. Фильтр с резким порогом прозрачности удалён.

## Стрелки, тени и переиспользование

Стрелки ответов, историй и hero сохранены из SVG, предоставленных пользователем, в папках question/, reviews/ и hero/. Одноцветные контуры используются масками с currentColor; тень hero вынесена на обёртку, чтобы маска не обрезала её. Из трёх экспортов карт исключены только 4px внешней тени справа/снизу (564×564 → 560×560), содержимое не перерисовывалось. Тень задаётся на .contact-map. Тень бейджа также задаётся в CSS.

В ui/data/blocks.json описаны назначение, исходники и подтверждённые источники компонентов. reusableComponents — примеры для копирования, не дополнительные блоки в статистике. Каталог доступен в /ui/statistics/. Открытые отличия от макета и состояния — в генерируемом STYLE-REMARKS.md.

## Проверка типографики

Отчёт — TYPOGRAPHY-AUDIT.md; подтверждённые значения — typography-audit.json. Команда pnpm check:typography проверяет 35 селекторов на 1920/1440/1200/390. Актуальные Figma-фреймы обновлены, мобильный вариант сверяется с прежним локальным эталоном.

Все шесть study-card — ссылки: каталог ведёт на /programs/, остальные пять временно используют href="#" без js-info и демонстрационного диалога. Адреса разделов подключаются при интеграции.

Переносы карточек возможностей сверены с актуальными фреймами 4200:19264, 4193:5015, 4193:7144 и прежним мобильным эталоном 4147:4976. Ширины текстовых групп задаются в feature-card.scss, подтверждённые переносы — br с классами видимости. В тексте новостей восстановлено «: сроки». Локальные снимки макетов — figma/opportunities-*.png, реализации — screenshots/abiturient/opportunities/.
